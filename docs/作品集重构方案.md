## 4. 视觉与设计构造

### 4.1 方向（沿用上次推荐 B，落地更具体）
- **底色** `#0B0B10`，卡片 `#14141C`，描边 `#23232F`；
- **唯一强调色**：琥珀 `#F5A524`（呼应乒乓的琥珀金；返航录深蓝作为第二色只用于该项目的卡图，不进入全局）；
- **字体**：中文用系统栈（PingFang / 微软雅黑），英文标题用 `Inter`（本地 vendor 一份 woff2，约 30 KB，不引 CDN）；
- **曲线与圆角**：统一 `--r-card: 20px`、`--r-pill: 999px`；
- **动效**：卡片 hover 只做 `translateY(-4px)` + 边框提亮；粒子背景**默认关闭**，用户可开（`localStorage`）。

### 4.2 设计 token（新建 `css/tokens.css`）

```css
:root{
  --bg:#0B0B10; --surface:#14141C; --line:#23232F;
  --text:#E6E6EE; --muted:#8E8EA6; --accent:#F5A524;
  --r-card:20px; --r-pill:999px;
  --fs-h1:clamp(40px,7vw,80px); --fs-h2:clamp(28px,3.4vw,40px);
  --sp-1:8px; --sp-2:16px; --sp-3:24px; --sp-4:40px; --sp-5:64px;
}
```

所有组件只用 token，不再写十六进制色值——**解决的正是现在 `#6366f1` 散落 6 处的问题**。

### 4.3 组件清单（一共 7 个，够用就好）
`card` / `badge` / `btn-primary` / `btn-ghost` / `section-head` / `stat` / `modal`。

## 5. 工程改造

| 项 | 现状 | 方案 | 取舍 |
|---|---|---|---|
| 样式 | Tailwind 410 KB 运行时 + 15 行 CSS + 5 处 `!important` | **A：手写 `tokens.css` + `components.css`（约 600 行）**；B：Tailwind CLI 预编译（≈15 KB） | 推荐 A：零构建，与你「无构建静态部署」一致；B 需要给 deploy 加一步 `npm run css` |
| 渲染 | 卡片手写 HTML | `projects.json` → `renderProjects()`（约 60 行） | 加项目只改 JSON |
| 弹窗 | `openPreview` 传 4 个参数写死 | 改为读 `projects.json` 的 id | 与上一条同源 |
| 图标 | iconify 运行时（22 KB + 按需请求） | 内联 SVG（用到的 ≤12 个） | 少一个依赖 |
| 图片 | PNG 直出 | WebP + `width/height` + `loading="lazy"` | 体积 −60%，CLS 0 |
| 无障碍 | 卡片是 `onclick` 的 `<article>`；`<a>` 在 `<div>` 里（`mt-4` 两个 a 连着写会挤成一行的问题也在这） | `<a role="link">` + 键盘可聚焦 + `aria-modal` | 键盘/读屏可用 |
| 打印/分享 | 无 OG 图 | 加 `og:title/og:description/og:image`（用乒乓台 glb 渲一张图当 OG） | 分享卡片好看 |

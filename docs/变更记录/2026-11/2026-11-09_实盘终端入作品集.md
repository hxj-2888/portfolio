## 一、现象/需求

- 桌面快捷方式 `实盘终端.lnk` 指向 `WorkBuddy/…/realtime-terminal/launcher.pyw`
  （`pythonw` 无控制台拉起 `node server.mjs` :8787）。它是一个**本地仓、无 git remote** 的项目：
  `realtime-market-terminal` v1.0.0，「实盘级 A 股 + 全球市场终端，Cloudflare Worker 聚合代理 + 单页前端」。
- 线上已部署：`https://market-terminal-ehg.pages.dev`，实测 200、title「实盘终端 · A股全市场监控」。
- 重做后的首屏主张「做能玩的网页作品」只覆盖游戏，加入非游戏的行情终端后表述失真。

## 二、根因/决策

| 项 | 决策 |
|---|---|
| 归类 | 进 `tools` 组（作品区），`countsAsGame:false` —— 不是游戏，不计入「可玩网页游戏」（仍 2） |
| 入口 | **只给线上地址，不给 GitHub/Gitee**：该仓没有 remote，编一个仓库链接就是撒谎 |
| 预览 | 不给「在线预览」：终端依赖 Worker 后端 + D1，静态内嵌副本跑不起来；`entry:null`、无 `source` |
| 版式 | `layout:data`：先把覆盖量摊开（5927 / 50 / 496），符合它「数据终端」的性质 |
| 作品色 | 新增 `--work-terminal:#5B21B6`（紫），与蓝/青/橙拉开；/paper 8.15:1、白字 8.98:1（实测） |
| 表述 | 首屏改「做能玩、能查、能盯盘的网页作品」；作品区「三款」→「四款」；meta/og 描述补终端；对账表「0 外部依赖」口径限定为**本站**（终端自带后端，避免误读） |

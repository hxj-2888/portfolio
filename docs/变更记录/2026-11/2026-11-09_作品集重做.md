## 一、现象/需求

- 用户要求「按 Anthropic Skills 重新烘出个人作品网页」。
- 读现状后发现旧版正是该 skill 点名的两类生成页胎记：同款圆角卡片 + 统一软阴影 +
  每个标题上方 ALL-CAPS eyebrow + `做<em>能玩</em>的` 单词斜体 + `浙江 · 可远程 · …` 中间点串 +
  `01/02/03` 编号（而那三条并不是序列）。
- 用户补充内容约束：主页展示乒乓对决 / 落幕查 / 新返航录三款；返航录栏目内含三个形态
  （经典 2.5D、3D、过渡式表单），其中表单式属游戏合集。

## 二、根因/决策

| 项 | 决策 |
|---|---|
| 设计对象 | 不是「好看的开发者主页」，而是「一个声称每个数字都能点开的人」。首屏改为工作台：核对清单 + 正在运行的产物；姓名与主张降级 |
| 色彩 | 中性底，色彩只属于作品（`.hue-*` 类）。保留 `#8A5A00` 的对比度推导结论，不因改版丢弃 |
| 零依赖 | 站点自称「0 外部依赖运行时」→ 不引字体 CDN / 框架 / 构建；中文性格靠字重字号字距 |
| 三形态 | 变成 `projects.json` 的 `versions` 数据；`status=local`（3D）**不配链接**——没有可打开的产物，给按钮就是把它画成「可做」 |
| 图标 | 按 portfolio AGENTS §2.8（缺署名素材一律不上站）移除手绘 inline SVG 图标层；文字链接已足够清楚。曾尝试取 Lucide 但 6 个里 4 个抓取失败，来源不全不如不用 |
| 装饰层 | `art.css` 清空：光晕 / 网格 / 辉光与主题无关，删 |
| 版式 | `layout` 分发：versions（返航录对账）/ split（乒乓规格）/ data（落幕查读数）/ note（合集与过程） |

# 2026-11-12 游戏合集补全 + 返航录 2.5D / 3D Demo 档位

> 现场记录。本批改 `projects/game-collection/index.html` / `collection.css` /
> `collection.js` / `COLLECTION-CHANGELOG.md`，以及 `projects.json` 里「游戏合集」
> 的摘要字段；需要重新部署才生效。**没有改 `games/` 里的同步产物，也没有改 3D 版数据。**

## 一、现象/需求

- 用户要求：个人网页的游戏合集「应当把所有游戏放进去」；返航录的 **2.5D 版和 3D 版**
  都需要留有 Demo 的档位。
- 现状：合集页只有两张卡——乒乓对决、返航录过渡式表单版；返航录 2.5D 只有一张
  「独立站 / 联机」外链，没有自己的 Demo 位；3D 版完全没有出现。
- 合集页还是 2026-10-21 的深色渐变卡片风格，与 2026-11-12 作品集首页的检验单版不一致。

## 二、根因/决策

| 项 | 决策 |
|---|---|
| 所有游戏 | 合集页改为 4 个条目：乒乓对决、返航录 2.5D、返航录过渡式表单、返航录 3D。前三个是可玩形态；3D 是唯一的 Demo 档位 |
| 2.5D Demo | 直接复用作品集已有的 `assets/projects/returnlog-demo.mp4`（相对路径 `../../assets/...`），不重新录制；旁边给「打开 2.5D」到独立站 |
| 3D Demo | 不伪造视频/版本号/链接。用虚线「Demo 档位预留」槽位，并留 `3D_DEMO_SLOT` HTML 注释；另一条工作流 Web 导出后替换媒体块即可 |
| 视觉 | 与首页检验单版对齐：浅纸底、墨字、朱红状态标记、1px 分栏线；去掉深色渐变、光晕、网格、圆角卡片与悬浮阴影 |
| 合集边界 | 合集页 `index.html` / `collection.*` 是手写维护，不参与 `sync.json` 复制；`games/` 仍是同步产物，本批不动 |
| 作品集摘要 | `projects.json` 的「游戏合集」`proof` 改为「2 个游戏 · 4 个形态」，`tagline` 补 2.5D / 3D Demo 档位；内联块重新生成 |
| 已否决 | 给 3D 塞占位视频/假版本号；把 2.5D 独立站直接 iframe 进合集（跨域 + 不必要，Demo 视频已足够）；改 `games/space-kill/` 或 `games/ping-pong/` |

## 一、现象/需求

- 用户要求：落幕查、乒乓对决、实盘终端各做演示视频；乒乓现在有看台 / 球员甲 / 球员乙
  三个视角，每个视角一条；「两个视频得连续」；实盘终端做一条小视频。
- 允许使用一切可用工具，包括 Remotion 与 ComfyUI。
- 本批把视频接入首页三个作品：乒乓作品项加三视角切换，落幕查与实盘终端用演示视频；
  首屏样张的落幕查也从静态图换成演示视频。

## 二、根因/决策

| 项 | 决策 |
|---|---|
| 乒乓三视角连续性 | 用**固定时间步 + 虚拟时钟**驱动游戏循环，三条视频从同一初始状态逐帧推进；12s 后三份引擎状态完全一致（`t=12.000`、比分 `1:0`、`rally=3`、球位/球员坐标一致）。看台 / 球员甲 / 球员乙是同一场同一时间线，两个球员视角逐帧对齐 |
| 「两个视频得连续」 | 用户未指明是哪两个；本批按最强解释落地：三名视角同一场；落幕查与实盘终端各自**单镜到底**（真实交互、无剪辑），标题卡与标注统一。若另有所指，按后续说明调整 |
| 落幕查 | 录真实站点 `delta-force-v5.pages.dev`：加载 → 搜索「建筑图纸」→ 首条建议 → 物品详情（当前价 + 近 30 天走势）；用 Remotion 去掉加载 logo 的 1s 并加标题卡/步骤条 |
| 实盘终端 | 线上 Worker 在录制时触发上游风控（「暂时拿不到行情数据」），改用本机 `realtime-terminal` 的 `node server.mjs`（端口 8787，真实全市场 5,929 只）录屏；展示全市场扫描、指数、板块/涨停榜 |
| 视频包装 | Remotion 4.0.543 做标题卡 + 左下标注，纸/墨/朱红与站点一致；**不生成或替换产品画面**，真实录屏为主体 |
| ComfyUI | 本机未安装 ComfyUI 主程序（`E:\ai-models` 只有 Qwen-Image 的 ComfyUI 格式模型）；本批没有用生成画面替代真实录屏，标题卡由 Remotion/CSS 绘制 |
| 站点接入 | `projects.json` 新增 `demoViews`（乒乓三视角）与 `demo`（落幕查/终端）；`site.js` 增加 `.media-viewer` 切换器；首屏落幕查 pane 改 `<video>`；内联数据重生成 |
| 已否决 | 用 AI 生成画面冒充游戏/产品录屏；把三视角剪成一条视频；用线上终端的风控错误画面；为 3D 置造 Demo |

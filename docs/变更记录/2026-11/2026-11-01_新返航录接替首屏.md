# 变更记录 · 2026-11-01 · 新返航录接替首屏主位

> 补记：本条涵盖 `f846b65`（及合并提交 `e1bf83f`）。2026-11-06 治理文档偏移时按 git 提交正文回填。

## 一、现象/需求

旧《返航录》已进入重做期（`space-kill-web` 侧正在重构），但它仍占着首屏展示台的主位和横幅卡。新的《新返航录》已经能跑，需要把它推到第一眼位置。

## 二、根因/决策

| 项 | 决策 |
|---|---|
| 首屏主位 | `projects.json` 里 `returnlog` 升为横幅（`band: true`、`order: 1`），`game-collection` 从横幅降为普通卡片 |
| 展示台默认页 | 默认停在「新返航录」的**实机演示视频**（会议讨论 / 投票那一段），旧《返航录》退出首屏，只保留在下方普通游戏卡片 |
| 数据带口径 | 不写死数字：「可玩网页游戏」由 `countsAsGame` 实时计算，本轮自动从 2 变 3 |
| 缩略图 | 之前 `returnlog` 没有卡图，只能借旧《返航录》的图——现在单独出图，避免两个条目看起来是同一个项目 |

## 三、改动（文件级）

| 文件 | 改动 |

## 书写约定

1. **一条记录一个文件**，文件名 = `YYYY-MM-DD_主题.md`，月目录 = `YYYY-MM`。
2. 每条必须写完五要素：现象/需求、根因/决策、改动（文件级）、验证（命令 + 读数）、未做/遗留/已否决。
3. 「验证」**只写能复跑的命令与读数**，不写「已验证」三个字了事（沿用乒乓 `AGENTS.md` §五）。
4. 站点代码改动 vs 纯文档改动要在「影响面」里分开写清楚，方便判断是否需要重新部署。

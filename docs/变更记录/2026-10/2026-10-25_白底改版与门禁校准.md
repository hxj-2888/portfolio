## 一、现象/需求

1. **深黑底难读**：强调色琥珀 `#F5A524` 在白底上对比度仅 1.7:1，不达 WCAG AA。
2. **改完 UI 部署不出去**：`b7b1fdc` 的白底改版被 `deploy.yml` 的「Verify committed projects/ is up to date with upstream」判红——仓库里入库的 `projects/` 停在旧版，而源仓库已前进。
3. **合集路径漏校验**：`b7b1fdc` 只补了独立副本（`projects/ping-pong-duel`、`projects/delta-force`），合集里的 `games/ping-pong`、`games/space-kill` 仍是旧版，deploy #75 继续红——原校验只按 5 个固定文件比对，正好没覆盖合集目录。
4. **合辑内 APK 下成网页**：内嵌副本的 APK 还是相对路径，作品集不承载二进制，相对链接落到 SPA 回退（200 + HTML），用户下到改名成 `.apk` 的网页。
5. **二维码功能等于不存在**：三张二维码图与 `#qrModal` 一直在，但 `renderCard` 从不生成 `[data-qr]` 元素。
6. **CSP 把内嵌游戏打坏**：根 `_headers` 严格 `script-src 'self'`，而内嵌副本有内联 `<script>`（sw.js 注册守卫等）。

## 二、根因/决策

| 项 | 决策 |
|---|---|
| 同步漂移 | 新增 `tools/verify-sync.cjs`：本地复现 `deploy.yml` 三步（浅克隆源仓库 → `--src-root` 重跑同步 → 逐字节比对），`--fix` 可写回。**不能直接同步本地兄弟目录**——本地 `太空杀游戏-完整版` 有 7 个未推送提交，会把旧版带进合集 |
| 合集路径漏校验 | 校验对象从「5 个固定文件」改为「整个 `projects/`」 |
| 内嵌副本适配 | 新增 `tools/fix-embedded-games.cjs`（幂等、只读已入库产物）。**必须是独立实现**：`sync.json` 的 `game-collection` 段是一条派生链，太空杀源缺失时整段失败退出，排在后面的补丁根本不会执行 |
| CSP 分层 | 第一版用「根严格 + `projects/_headers` 放宽」，线上实测不生效（`projects/ping-pong-duel/` 拿到的仍是根策略）。改为**根 `_headers` 写两行同名 `Content-Security-Policy`**：HTTP 允许多个同名响应头，CSP 按规范取**交集**，`'self'` 是 `'unsafe-inline'` 的子集，浏览器只执行更严的那条——首页走严格版，内嵌副本的内联脚本照常运行。删除 `projects/_headers` |

# 变更记录 · 2026-10-21 · 作品集重构 v2 + 游戏合集上线 + 正文原件更新

> 口径更新：**两个游戏做合集、不做功能合并** → 合集页已落地；**作品集整体重构、删除评分与不真实数据** → 已完成；**返航录改名（仅展示名）** → 已按「返航录」；**正文↔代码同步** → 原件、站点、映射、门禁四件套已就位；**美术设计优化（第 5、6 项）暂缓**。

## 现象 / 需求

1. 游戏合集：两个网页游戏并排为一站入口，彼此独立；
2. 作品集重构：「4.8/5 评分」「3 年经验」「4 个行业」等无来源数据要删，内容与结构都要改；
3. 返航录改名：**只改展示名**，仓库名与网址不动；
4. 正文与代码同步：作者新发的 4 份 PDF（正文 / 职业速查卡 / 术语表 / 判定流程图）作为权威原件。

## 根因 / 决策

1. **合集 = 外壳，不是合并**：`sync.json` 新增 `game-collection` 段，把两个游戏的产物白名单搬进 `games/`；合集页手写，不接管游戏逻辑；联机跳各自独立站。
2. **作品集改为数据驱动**：`projects.json` 成为唯一真相，首页卡片与弹窗都由 `js/site.js` 渲染；删除全部不可验证数据，定位改为「独立开发者」。
3. **改名只动展示层**：`id`、目录、域名、URL 全部保留 `space-kill`；作品集与新卡图统一显示「返航录」。
4. **正文同步做成四件套**：权威 PDF 入库 → 重抽正文 md → 生成 `rules-map.json` → `check-rules-sync.cjs` 四条校验进 `npm run check`。

## 根因 / 决策

1. **合集 ≠ 合并**：合集只承载「入口 + 统一视觉 + 版本信息」，两个游戏代码零改动；命名 `game-collection`；**返航录仓库名与域名一律不改**。
2. **改名只改展示层**：`id / 目录 / 仓库 / 域名 / URL` 全部冻结，避免历史链接与部署失效；历史文档里的「太空杀」保留原文。
3. **作品集是「重构」不是「优化」**：删掉「4.8/5 合作满意评分」「3 年经验」「4 个服务行业」等不可验证数据；定位从「设计师」改为「独立开发者」；结构改为「作品分组 + 做法 + 可验证数据 + 联系」。
4. **正文同步先定权威原件**：微信发来的 4 份 PDF 与仓库内 PDF 不是同一文件（哈希不同，仓库正文 PDF 5.61 MB vs 微信 1.54 MB），且**速查卡/术语表/流程图仓库里没有**。先确认权威原件，再谈「正文↔代码」同步。
5. **美术优化先统一 token**：四个项目各自为战是视觉不一致的根因，先做全局 token + 图标替换，再逐项目微调。

## 〇、给接手的人：三句话

1. **`projects.json` 是唯一真相**。首页卡片与预览弹窗都由 `js/site.js` 从它渲染，
   不要再去 `index.html` 里手写卡片——那是重构前的做法，已经删了。
2. **视觉分两层**：`tokens.css`（变量）→ `components.css`（组件）→ `page.css`（页面）
   是**功能层**，`art.css` 是**装饰层**。改配色只动 `tokens.css`；`art.css` 整个删掉页面照样能用。
3. **两个游戏是「合集」，不是「合并」**。合集页只做入口，游戏代码零改动；
   联机一律跳各自独立站。不要试图把两个游戏揉进一个引擎。

### 一条命令跑完全部门禁

```bash
npm run check         # check-copy + check-rules-sync + check-headers + check:embedded
npm run sync:verify   # 与源仓库逐字节比对（deploy.yml 同款流程，太空杀默认跳过）
npm run sync:verify:fix  # 有差异时写回
npm run sync          # 同步 + 内嵌适配（需要本地兄弟目录，CI 不用）
```

## 二、作品集是怎么渲染出来的

```
fetch('projects.json')
  → 按 order 排序
  → 遍历 [data-group="play|tools|process"] 容器
  → 每个项目 renderCard()：
       有 thumbnail → 建 .card__media（图 + 顶部项目色条）
       无 thumbnail → 建 .card--note（无图区，图标并入 eyebrow 行）
       有 entry && source → 显示「在线预览」（打开 modal iframe）
       有 liveUrl → 显示「打开站点」（新窗口）
  → 数据带的「可玩网页游戏」数量由 countsAsGame 实时计算
```

**为什么这么设计**：重构前卡片是手写 HTML，加一个项目要改两处、还容易漏。
现在只改 `projects.json`。

### 卡片信息分级（别把长文塞回卡片）

| 层级 | 内容 |
|---|---|
| L1 卡片 | 类别、标题、**一句 ≤28 字**、3 个标签、主链接 |
| L2 弹窗 | 预览、关键数据、技术要点 |
| L3 详情 | 长文、变更记录、下载 |

## 三、游戏合集

- 合集页 `projects/game-collection/index.html` **手写**，两卡并列，各带「开始游玩 / 独立站 / 规则与资料」。
- 两个游戏由 `sync.json` 的 `game-collection` 段白名单搬进 `games/`（109 个文件，**0 个 APK**）。
- **iframe 内不注册 Service Worker**：合集页头部有 `window.__ARCADE_SW__` 标记，
  `sync-projects.js` 每次同步探测它（不命中仅告警，不阻断）。
- 联机跳独立站：`ping-pong-duel.pages.dev` / `space-kill-web.pages.dev`。

### 补丁机制（复用 delta-force 那套，别新造）

`sync.json` 的 `patches` 支持 `regex` / `string` 两种规则，配 `okIfContains` 做幂等。
**新增补丁前先跑 `sync:dry` 看「未匹配」告警**，不要凭猜写规则。

⚠ **`game-collection` 段是一条派生链**：它把两个游戏搬进 `games/`。任一源缺失
（例如太空杀重做期间）整段会失败退出，**排在后面的补丁都不会执行**。所以合集内嵌
副本的适配另有一份独立实现 `tools/fix-embedded-games.cjs`（幂等、只读已入库产物），
`npm run sync` 与 `tools/verify-sync.cjs` 都会调用它。改适配规则时**两处都要改**。

## 四、正文 ↔ 代码同步（返航录）

### 链条

```
权威 PDF（attachment-site/规则正文/）
  → 抽取 md（docs/_返航录v1preview1.0_提取.txt，gitignore）
  → build_site.py → site/rules.html
  → 站点部署

rules-map.json（条款 260 条 + 测试锚点）
  ← gen-rules-map.cjs 从 test-fix-v26.cjs 的**断言名**里提取
```

### 四条校验（`check-rules-sync.cjs`）

| 项 | 查什么 | 失败意味着 |
|---|---|---|
| A | 正文条款 ⊆ 已登记条款 | 新增条款没登记，跑 `npm run rules:map` |
| B | 锚点指向的测试文件真实存在 | 锚点悬空，测试文件被改名/移动 |
| C | PDF / md 的 sha256 与登记一致 | 原件换了但没重登记 |
| D | 站点 rules.html 覆盖 ≥95% 条款 | 正文更新了但站点没重建 |

### 当前读数

```
条款 260 · 已覆盖 102 · 未覆盖 158 · 覆盖率 39.2% · 锚点 274
```

### ⚠ 两个已知的解析坑（改这两个脚本前必读）

1. **夜间步骤号会被当成条款**：正文 md 里 `#### 0.1 外星人蛰伏…` 是**步骤号**不是 §0 条款。
   过滤必须按**标题形态**（长度 >24 / 以标点开头 / 含动作词），
   **不能按编号白名单**——`0.5 裁判次序`、`0.6 术语统一` 既是步骤号也是真条款，按编号会误杀。
2. **`\s` 会跨行匹配**：`#### 3.3.10` 后面那行正文会被当成标题。
   分隔符必须用 `[ \t]`、标题类用 `[^\r\n]`。
   gen 与 check **必须用同一套过滤**，否则会出现「正文 259 / 登记 260」的假差异。

### ⚠ 附件站曾经没有 CI

2026-10-21 之前 `space-kill` 靠手动 `wrangler pages deploy`，**已因此漏发过三份规则 PDF**
（线上返回 `text/html` 的 SPA 回退，而仓库里文件齐全）。

现在 `deploy.yml` 里有两条保护：

- 部署前：重建 `site/` 与提交版 `diff -r`，不一致即失败；
- 部署后：**四份 PDF 必须 `application/pdf` + 首字节 `%PDF`**（只看 HTTP 200 会被 SPA 回退骗过去）。

### 推送注意

- 两个仓库都有 `origin`(GitHub) 与 `gitee` 两个远端，**都要推**。
- **CI 会在你推送间隙往 `portfolio` 提交**（`sync-attachment-site` 工作流）。
  推前先 `git fetch origin`，发现分叉就 **`git rebase`**（不是 merge），
  rebase 后 Gitee 需 `--force`（那里只有自己的旧副本才可强推）。

## 六、设计约定（改样式前先看）

> **2026-10-25 改版**：全站换成白底（`--bg:#F7F8FA`），强调色由琥珀 `#F5A524`
> 换成深琥珀 `#8A5A00`（原琥珀在白底上对比度仅 1.7:1，不达 WCAG AA）。
> 版式改为「首屏展示台 → 数据 → 作品 → 做法 → 联系」，合集降级为横幅。

1. **只有一个强调色**：深琥珀 `#8A5A00`（hover `#6E4800`，浅底 `#FDF4E3`）。项目二级色（乒乓青、返航录蓝、落幕查橙）只用于该项目的**圆点**，不进全局组件。
2. **不用 emoji 当 UI 图标**，一律线性 SVG（stroke 1.6，24 网格）。
3. **不引 CDN**：Tailwind 运行时与 iconify 已在重构时删除（曾占 410 KB + 22 KB）。
4. **卡片缩略图统一 1200×750**；无图的条目不要留空图区。
5. **首屏可验证**：首页每个数字都必须能点开验证，不许出现评分/年限/行业数这类无来源数据（`check-copy.cjs` 会拦）。
6. **CSP 分两层**：根 `_headers` 严格（`script-src 'self'`），`projects/_headers` 对内嵌副本放宽 `'unsafe-inline'`（游戏副本仍有内联脚本）。改完跑 `npm run check:headers`。
7. **动效统一受 `prefers-reduced-motion` 控制**，新增动效必须走 `tokens.css` 的 `--dur` 或 `matchMedia` 判断。
8. **分享图**：`assets/og.png` 为 1200×630 标准比例，改动标题文案后需要重做。

| 文件 | 用途 | 规格 |

  据此渲染 `<video muted loop playsinline>`，`bindDemoVideos()` 用 IntersectionObserver
  **进视口才播、离开即停**（不为屏外内容付解码成本）。

- **源视频怎么来的**：游戏仓 `npm run record:demo`（`tools/record-demo.cjs`），
  用 CDP `Page.startScreencast` 抓整页帧（canvas + 比分 HUD 一起入镜），

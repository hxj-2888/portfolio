## 〇、给接手的人：四句话

1. **`projects.json` 是唯一真相**。首页检验项与预览弹窗都由 `js/site.js` 从它渲染；
   构建时 `tools/inline-projects.cjs` 把同一份数据写进 `index.html` 的 `#projects-data`，
   页面不再依赖第二次 `fetch`。改数据后跑 `npm run data:inline`，不要手改内联块。
2. **视觉分三层**：`tokens.css`（变量）→ `components.css`（组件）→ `page.css`（版面）。
   `art.css` 在 2026-11-09 重做时**清空**了（光晕/网格属通用装饰）；改配色只动 `tokens.css`。
3. **游戏是「合集」，不是「合并」**。合集页只做入口，游戏代码零改动；
   联机一律跳各自独立站。不要试图把几个游戏揉进一个引擎。
4. **推之前先跑 `npm run check:docs:all`**。不绿就说明代码改了文档没跟上，`git push` 时的 hook 也会再拦一次。
   规则见 `AGENTS.md` §二（2026-11-06 起强制）。

## 二、作品集是怎么渲染出来的

```
内联 #projects-data（tools/inline-projects.cjs 从 projects.json 生成）
  → 缺失时才 fetch('projects.json') 兜底（避免网络抖动把整块作品区打成空白）
  → 按 order 排序（band 优先）
  → renderSampleTabs()：首屏样张标签**从 DOM 里已存在的 .artifact__pane 反查项目**，
       保证「标签说在跑」与「实际能切的产物」不会各写一份而漂移
  → renderCases()：按 layout 分发版式
       versions → 返航录的 2.5D / 3D 拆成两条独立检验项：
                  2.5D = 整宽实机视频 + 规格 / 入口；3D = 整宽虚线 Demo 槽位
                  （与落幕查媒体同一量级；过渡式表单版放在 2.5D 项末尾）
       split    → 媒体 + 规格表（乒乓）
       data     → 读数表 + 图（落幕查 / 实盘终端）
       note     → 紧凑信息块（合集 / 过程资料）
       3D 的 status=local 只用于「待接入」状态，不再渲染成版本表里的浅槽
  → renderRecord()：验收章「在线 4 / 待检 1」与核对记录「4 / 2 / 1 / 0」全部实时计算
  → mediaEl()：p.demoViews → .media-viewer（乒乓看台/球员甲/球员乙切换，同一场）；
       p.demo → 单视频；否则 thumbnail（落幕查/实盘终端已用真实录屏视频）
```

**为什么这么设计**：重构前卡片是手写 HTML，加一个项目要改两处、还容易漏。
现在只改 `projects.json`，再跑 `npm run data:inline`。2026-11-12 的检验单版
不再依赖第二次网络请求：数据随首页一起下发，链路抖动不会让作品区消失。

### 面板信息分级（别把长文塞回面板）

| 层级 | 内容 |
|---|---|
| L1 面板 | 标题、一句 lead、该作品性质对应的版式（对账/规格/读数）、主链接 |
| L2 弹窗 | 预览、关键数据、技术要点 |

## 三、游戏合集

- 合集页 `projects/game-collection/index.html` **手写**，四条目：乒乓对决、返航录 2.5D、返航录过渡式表单、返航录 3D Demo 槽位。前三个可玩；3D 是虚线槽位（`3D_DEMO_SLOT` 注释处，Web 导出后替换媒体块）。
- 2.5D 的 Demo 用 `../../assets/projects/returnlog-demo.mp4`；3D 不伪造视频/版本号/链接。
- 两个游戏由 `sync.json` 的 `game-collection` 段白名单搬进 `games/`（109 个文件，**0 个 APK**）。
- **iframe 内不注册 Service Worker**：合集页头部有 `window.__ARCADE_SW__` 标记，
  `sync-projects.js` 每次同步探测它（不命中仅告警，不阻断）。
- 联机跳独立站：`ping-pong-duel.pages.dev` / `space-kill-web.pages.dev`。

### 补丁机制（复用 delta-force 那套，别新造）

`sync.json` 的 `patches` 支持 `regex` / `string` 两种规则，配 `okIfContains` 做幂等。
**新增补丁前先跑 `sync:dry` 看「未匹配」告警**，不要凭猜写规则。

⚠ **`game-collection` 段是一条派生链**：它把两个游戏搬进 `games/`。任一源缺失
（例如太空杀重做期间）整段会失败退出，**排在后面的补丁都不会执行**。所以合集内嵌
副本的适配另有一份独立实现 `tools/fix-embedded-games.cjs`（幂等、只读已入库产物），
`npm run sync` 与 `tools/verify-sync.cjs` 都会调用它。改适配规则时**两处都要改**。

### 链条

### 四条校验（`check-rules-sync.cjs`）

| 项 | 查什么 | 失败意味着 |
|---|---|---|
| A | 正文条款 ⊆ 已登记条款 | 新增条款没登记，跑 `npm run rules:map` |
| B | 锚点指向的测试文件真实存在 | 锚点悬空，测试文件被改名/移动 |
| C | PDF / md 的 sha256 与登记一致 | 原件换了但没重登记 |
| D | 站点 rules.html 覆盖 ≥95% 条款 | 正文更新了但站点没重建 |

### 当前读数（2026-11-06 复跑）

```
条款 260 · 已覆盖 102 · 覆盖率 39% · 锚点 274（其中 234 条当前悬空，见下）
```

> ⚠ **234 条锚点悬空是环境造成的，不是新增债**：锚点指向
> `../太空杀游戏-完整版/tools/test-fix-v26.cjs`，该目录已被删除/改名。
> 恢复源目录后重跑 `npm run check:rules`，悬空数应回到 0。
> A（正文 md 缺失）与 C（PDF/md 指纹缺失）同理，都因为找不到源仓库。

### ⚠ 两个已知的解析坑（改这两个脚本前必读）

1. **夜间步骤号会被当成条款**：正文 md 里 `#### 0.1 外星人蛰伏…` 是**步骤号**不是 §0 条款。
   过滤必须按**标题形态**（长度 >24 / 以标点开头 / 含动作词），
   **不能按编号白名单**——`0.5 裁判次序`、`0.6 术语统一` 既是步骤号也是真条款，按编号会误杀。
2. **`\s` 会跨行匹配**：`#### 3.3.10` 后面那行正文会被当成标题。
   分隔符必须用 `[ \t]`、标题类用 `[^\r\n]`。
   gen 与 check **必须用同一套过滤**，否则会出现「正文 259 / 登记 260」的假差异。

> 颜色只保留朱红（验收章 / 待检）与松绿（在线），正文一律深字浅底。
> 数据也改为随首页下发：`projects.json` 由 `tools/inline-projects.cjs` 内联进 `#projects-data`。
> 2026-11-13：returnlog 的 2.5D / 3D 拆成两条独立检验项；2.5D 用整宽实机视频，

1. **色彩**：纸 `#F3F5F6` / 墨 `#0F1418` / 朱红 `#A33A2A` / 松绿 `#0B5C40`；不再给作品分配色块。
   正文 16.94:1、次要文字 7.20:1、朱红 6.01:1、松绿 7.33:1（WCAG 2.1 实算）；白字只出现在朱红按钮上（6.57:1）。
2. **字体**：宋体承担大标题 / 作品名（`--font-display`），黑体承担正文与控件，等宽只给真数据串。
   不用 ALL-CAPS 小标签、不用单词斜体强调、不用中间点元信息串。
3. **版式**：220px 边栏 + 右侧正文；作品区沿用同一条栏线，每件作品一行「检验项」；
   returnlog 的 2.5D / 3D 是两条独立检验项；3D 是整宽虚线 Demo 槽位（与落幕查媒体同量级），不配按钮。
4. **不用图标**：2026-11-09 起移除手绘 inline SVG 图标层（AGENTS §2.8）；文字链接已足够。也不引 emoji 当图标。
5. **媒体**：有实机录屏的用录屏（静音循环），只有界面的用截图；无图条目不留空图区。
6. **CSP 两层**：根 `_headers` 严格（`script-src 'self'`、`style-src 'self'`）；
   `/projects/*` 先用 `! Content-Security-Policy` 删掉继承的严格策略，再设允许 `'unsafe-inline'` 的宽松策略。
   首页不写内联 style；唯一的内联 script 是 JSON-LD 与 `#projects-data`（数据块，不执行）。改完跑 `npm run check:headers`。
7. **动效**：全站只有验收章那一次盖章（只动 transform，不动 opacity），受 `prefers-reduced-motion` 控制；
   reduced-motion 下视频不自动播放。
8. **3D 槽位**：由 `projects.json` 的 3D 形态 `status=local` 驱动，渲染为独立检验项 + 整宽虚线 Demo 槽位；
   另一条工作流把它改成 `live` 并补 `url` 后，把 `demoSlotEl` 换成 `mediaEl` 即可上线。不要伪造版本号或链接。
9. **分享图**：`assets/og.png` 仍是旧版视觉，改标题文案后需要重做。
